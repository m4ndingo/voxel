🎨 Paletas temáticas para VoxelForge — propuesta

Candidatas de paletas agrupadas por tema/color para sustituir (o complementar) la paleta única actual de 24 colores. Elige las que quieras y las integro como paletas conmutables en el panel «Paleta».

Cómo se integraría (cuando apruebes las temáticas): un selector encima de las muestras del panel «Paleta» para cambiar de paleta activa; PALETTES = { clasica:[…], bosque:[…], … } reemplaza al array plano PALETTE; buildPalette() pinta la paleta elegida y se recuerda en localStorage. Los colores personalizados (input + cuentagotas) seguirían funcionando igual.
· Pasa el ratón por cada muestra para ver el hex · clic para copiarlo.
✏️ Es una propuesta: dime qué paletas dejamos (y si quieres renombrar/retocar colores o fijar el nº de muestras por paleta). Con eso las cableo en el editor. Artefacto servido en /paletas_propuesta.html.
